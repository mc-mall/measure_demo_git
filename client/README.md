# 客户端服装需求确认原型

本目录照搬现有 `2.measure-client/h5` 的页面、字段和交互。

## 访问

在仓库根目录启动静态服务器后访问：

```text
http://localhost:8767/client/
```

## 当前交互

- 员工登录，不提供自主注册
- 登录后查看归属订单，从订单点击“预约量身”，已有预约时先提示并提供查看及取消入口
- 订单卡提供“提交售后”：员工选择服装、数量及逐项修改要求，提交后到门市退还
- “我的订单”中按申请逐条展示记录摘要：订单号、申请编号、提交时间和当前进度节点
- 点击记录进入售后详情，展示完整进度、退换服装的申请数量与累计签收数量、逐项修改要求、申请备注及最近一次门市签收信息，不展示处理日志
- 返回列表保留滚动位置，支持连续查看多次申请；详情会同步门市更新后的进度
- 登录后从具体订单进入“量体预约”，只查看管理后台为该订单开放的服务地址、服务时间、最大预约人数和当前预约人数
- 量体预约页采用“量体地址 → 弹窗月历 → 预约时间段”三级联动；正文仅保留已选日期，月历仅开放实际可预约日期并支持跨月切换，时段显示“已预约人数/预计可接待人数”，预约成功后以弹窗反馈
- 可预约区域只显示当前员工能够登记的时段：本人已预约、已关闭、满额且禁止超额的时段不显示
- 员工取消预约后释放名额；原时段已关闭，或该时段不支持超额预约时，不能重新预约该时段
- 员工可登记或取消自己的预约；满额且不支持超额的时段不可登记，支持超额的时段满额后仍可登记
- 售后进度：提交售后 → 门市收货 → 已下单到工厂 → 工厂交付，待派送 → 完成派送；签收后显示签收人和时间
- 订单进度：服装确认 → 预约量身 → 完成量身 → 已下单到工厂 → 工厂交付，待派送 → 已交付
- 补充身高、体重、电话和邮箱
- 女性员工孕妇分支
- 员工完成数量确认及签字后，将验证状态同步到同源管理后台；后台撤销后可重新确认
- 内容确认、电子签名和结果锁定
- 忘记密码、验证码及新密码校验流程

## 售后数量与关闭状态

- 每次售后申请独立保存；申请数量不会被门市实收数量覆盖。
- 服装优先读取员工已确认明细，未确认时使用所属订单按性别配置的服装和默认数量。申请数量为正整数且不超过可申请数量，修改要求必填。
- 详情显示“申请数量 / 签收数量”，后者为所有签收批次的累计实收量。例如申请 2 件、首次带来 1 件，分别显示 2 件和 1 件；第二次再签收 1 件后累计显示 2 件。
- 尚未签收时显示“待签收”；旧记录缺少实收数据时显示“未记录”，不自动认定已全部收货。批次中实收为 0 的服装正常显示 0 件。
- 门市可在送厂前单独关闭某项服装申请，详情显示“已关闭”和原因，例如毛衣“现场退换”；原申请及签收数量保留，其他服装继续处理。
- 全部服装关闭时整单显示“已关闭”，不显示等待工厂处理；未全部关闭时仍按有效服装继续推进。
- 门市分次签收的详细操作记录保留在后台，员工端显示完整业务进度、累计数量及最近签收人、时间、备注，不展示处理日志。

## 原型数据规则

- 员工账号按订单与员工 ID 匹配，密码输入不保存或校验明文。
- 验证码仅演示输入和格式校验，输入任意 6 位数字即可。
- 签字确认及退换预约会写入与管理后台共用的同源 `localStorage`；申请记录展示员工提交及门市处理的数据，仅用于原型联动展示。
