# 客户端服装需求确认原型

本目录照搬现有 `2.measure-client/h5` 的页面、字段和交互。

## 访问

在仓库根目录启动静态服务器后访问：

```text
http://localhost:8767/client/
```

## 当前交互

- 员工登录，不提供自主注册
- 补充身高、体重、电话和邮箱
- 女性员工孕妇分支
- SKU 选择及总数量等于 4 的校验
- 内容确认、电子签名和结果锁定
- 忘记密码、验证码及新密码校验流程

## 原型数据规则

- 员工账号按订单与员工 ID 匹配，密码输入不保存或校验明文。
- 验证码仅演示输入和格式校验，输入任意 6 位数字即可。
- 确认结果仅保存在当前页面运行状态，刷新页面会重置。
