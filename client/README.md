# 客户端服装需求确认原型

本目录照搬现有 `2.measure-client/h5` 的页面、字段和交互。

## 访问

在仓库根目录启动静态服务器后访问：

```text
http://localhost:8767/client/
```

## 当前交互

- 员工登录，不提供自主注册
- 登录后查看归属订单，从订单点击“退换登记”自主提交申请
- 退换申请勾选服装后直接填写逐项换货 / 修改需求及补充说明，提交后状态为“已登记”
- 客户端查看自己的退换申请列表及管理后台更新后的状态
- 退换状态与管理后台统一为“已登记 / 已处理 / 已完成”，其中“已完成”为本轮终态
- 补充身高、体重、电话和邮箱
- 女性员工孕妇分支
- SKU 选择及总数量等于 4 的校验
- 员工完成数量确认及签字后，将验证状态同步到同源管理后台；后台撤销后可重新确认
- 内容确认、电子签名和结果锁定
- 忘记密码、验证码及新密码校验流程

## 原型数据规则

- 员工账号按订单与员工 ID 匹配，密码输入不保存或校验明文。
- 验证码仅演示输入和格式校验，输入任意 6 位数字即可。
- 签字确认及退换申请会写入与管理后台共用的同源 `localStorage`，仅用于原型联动展示。
