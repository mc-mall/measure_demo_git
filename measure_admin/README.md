# MC 量体管理后台原型

本目录是从现有 `measure-admin` 初始化的独立静态管理后台原型。

当前保留以下交互：

- 原型登录与退出
- 总览统计
- 裁缝师、订单、员工的新增、编辑与删除
- 创建或编辑订单时，按男士、女士配置客户端可选服装类型
- 为每个服装类型配置默认数量，以及员工是否可以更改数量
- 可选配置同一性别下多个服装类型的组合数量限制，支持“刚好”和“不多于”条件
- 从具体订单进入签字明细，按员工查看客户端确认的各服装数量与验证状态，支持搜索、分页、导出，并撤销已完成的签字验证
- 员工筛选、分页、批量导入和量体档案模板导出
- 员工量体档案、版本修改与移除
- 男士、女士量体记录筛选、分页与 CSV 导出
- 量体版本对比分析向导与结果导出
- 退换登记：搜索员工、带出对应服装和数量、填写换货或修改需求并保存
- 退换需求支持按员工 / 登记编号、单位名称、登记时间和状态筛选，支持当前页一键全选可处理记录
- 退换列表支持 15 / 50 / 100 条每页、详情查看及“已登记 / 已处理 / 已完成”批量状态修改

## 退换登记流程

1. 店员点击“新建售后”，输入员工编号并选择对应员工。
2. 原型按员工归属订单及性别读取订单中已配置的服装类型和默认数量。
3. 店员勾选本轮涉及的服装，填写数量和每项换货 / 修改需求。
4. 保存后生成独立登记编号，初始状态为“已登记”。
5. 列表可批量修改为“已登记”“已处理”或“已完成”，详情保留每次状态变化记录。
6. “已完成”表示本轮需求结束，该记录不再允许勾选修改；员工有二次修改需求时重新新建登记，不覆盖原记录。

退换登记数据与其他原型数据一样保存在当前浏览器 `localStorage` 中，只用于交互展示，不接入正式服务端或数据库。

## 本地运行

在仓库根目录启动任意静态服务器。例如：

```bash
python3 -m http.server 8767
```

然后访问：

```text
http://localhost:8767/measure_admin/
```

## 数据说明

- 原型数据保存在当前浏览器的 `localStorage` 中，不连接生产数据库。
- 登录页接受任意非空账号和密码，仅用于演示登录流程，不会保存输入内容。
- 裁缝师密码不以明文写入源码、页面或浏览器存储；列表仅展示是否已设置。
- 裁缝端与本后台在同一站点下共享订单、员工及量体记录数据。
- 客户端与本后台共享员工签字验证状态；客户端签字后转为已验证，后台撤销后恢复未验证。
- 清理站点数据会重置原型数据。
