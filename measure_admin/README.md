# MC 量体管理后台原型

本目录是从现有 `measure-admin` 初始化的独立静态管理后台原型。

当前保留以下交互：

- 原型登录与退出
- 总览统计
- 裁缝师、订单、员工的新增、编辑与删除
- 员工筛选、分页、批量导入和量体档案模板导出
- 员工量体档案、版本修改与移除
- 男士、女士量体记录筛选、分页与 CSV 导出
- 量体版本对比分析向导与结果导出

## 本地运行

在仓库根目录启动任意静态服务器。例如：

```bash
python3 -m http.server 8767
```

然后访问：

```text
http://localhost:8767/measure_admin/
```

## 数据说明

- 原型数据保存在当前浏览器的 `localStorage` 中，不连接生产数据库。
- 登录页接受任意非空账号和密码，仅用于演示登录流程，不会保存输入内容。
- 裁缝师密码不以明文写入源码、页面或浏览器存储；列表仅展示是否已设置。
- 裁缝端与本后台在同一站点下共享订单、员工及量体记录数据。
- 清理站点数据会重置原型数据。
