# 裁缝端量体原型

本目录照搬现有 `3.measure-tailor/h5` 的页面、字段和交互，并调整为与当前静态管理后台原型联动。

## 访问

在仓库根目录启动静态服务器后访问：

```text
http://localhost:8767/tailor/
```

## 原型数据规则

- API Base URL 留空时使用浏览器本地原型数据。
- 登录账号与管理后台“裁缝师管理”中的账号匹配。
- 登录密码仅保留输入交互，不保存或校验明文。
- 订单、员工和提交后的量体记录与管理后台共享。
- 填写 API Base URL 时，保留原有远程 API 请求方式。

## 产品版型量身（2026-09-19）

- 本机模式下，后台已配置产品时，按员工性别显示产品，逐个选择版型并量身；尚未配置产品时保留原有固定字段流程。当前产品配置未绑定订单，因此此处按性别读取全部对应产品。
- 版型名称平铺单选；字段默认折叠，点击字段展开填写，同时收起上一个字段。折叠摘要保留默认值及本次结果，展开和收起不清空输入，校验失败时展开对应字段。
- 数字字段显示产品内保存的版型默认值，可选择“版型加减”或“净体录入”。加减量支持正负数及小数，留空按 0 计算；成衣尺寸为版型默认值加调整量，并校验产品配置的上下限。
- 净体模式记录实测尺寸，不由成衣尺码推算，不套用成衣上下限；版型缺少默认值的字段使用净体模式。必填字段不能留空。
- 单选、多选属于产品通用字段，以平铺单选按钮 / 多选标签显示，初始不预选；可在选择版型前录入，切换版型保留已选项。后台支持逐行、逗号或顿号配置选项，并提供“特体”示例；旧的按版型选项默认值停用，在保存产品时移除。
- 更换版型时，如已填写版型相关数据会确认后清空该部分输入，保留通用选项；切换产品或录入方式保留当前输入。下一笔量身清空上一笔数据。
- 确认页与提交记录保留产品、版型、字段快照、录入方式、默认值、加减量或净体尺寸；后台量体列表及 CSV 明细可核对。后台后续修改配置不影响已提交记录。

## 订单进度联动

首次打开裁缝端也会初始化共享演示数据。提交量体记录后，客户端和后台按员工与订单匹配该记录，更新“完成量身”进度；后续工厂及派送由管理后台推进。

## 预约明细（2026-09-16）

- 本机原型模式登录后，可在任意量身步骤打开“预约明细”；弹窗关闭后保留原步骤、员工和未提交字段，不改变原有查询、量体、提交及下一笔流程。
- 默认查看今天，支持按日期、订单、时段（含地址）和待量身 / 已量身筛选，统计当前日期、订单及时段的有效预约人次。暂停时段已有的有效预约仍显示，取消预约不显示。
- 已量身依据同订单、同员工在预约当天（北京时间）且预约登记后提交的量体记录判断，允许早到或迟到。历史记录、其他订单记录不会误标；缺少有效时间的旧记录不推断完成。此处是预约当天的执行状态，与订单累计进度口径不同。
- 人员名单仅显示“员工编号 姓名”，多个人员之间用中文分号“；”分隔，例如 `EMP001 陳嘉儀；EMP002 李國輝`。名单不重复展示单位、订单、地址、时间或状态标签，量身状态通过上方筛选和统计查看。
- 查看名单为只读操作，不切换当前员工，不自动标记完成。原有手动查询继续支持无预约员工。
- 打开、手动刷新、窗口重新获得焦点或同源其他标签页更改数据时更新名单。数据仅在当前浏览器同源共享；远程 API 模式不显示此本机预约入口。
